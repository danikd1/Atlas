# SberAgency Crawler

Пайплайн для сбора, фильтрации и суммаризации статей с Habr.

## Возможности

- 📥 Сбор статей из RSS-лент Habr
- 🔍 Фильтрация по ключевым словам с лемматизацией
- 🎯 Фильтрация по эмбеддингам (semantic similarity)
- 📄 Извлечение полного текста статей
- 📝 Суммаризация статей с помощью LLM (GigaChat)
- 📊 Оценка метрик пайплайна на размеченном датасете
- 🌐 Веб-интерфейс для отображения результатов и прогресса

## Установка

1. Клонируйте репозиторий (или используйте существующий проект)

2. Установите зависимости:
```bash
pip3 install -r requirements.txt
```

3. Настройте таксономию и выбор узлов: ключевые слова задаются в `data/taxonomy.json` (узлы D/GA/A); выбранные узлы для пайплайна — в `config.config.TAXONOMY_SELECTION`.

## Использование

### Запуск пайплайна из командной строки

```bash
python3 -m src.main
```

Результаты сохраняются в `outputs/articles_filtered.csv`.

### Запуск веб-сервера

```bash
python3 run_server.py
```

Затем откройте в браузере: http://127.0.0.1:8000

Веб-интерфейс позволяет:
- Запускать пайплайн с отслеживанием прогресса в реальном времени
- Просматривать дайджест статей
- Видеть метрики выполнения пайплайна
- Оценивать метрики на размеченном датасете

### Оценка метрик

Для оценки метрик на размеченном датасете `metrik.xlsx`:

```bash
python3 evaluate_metrics.py
```

Или через веб-интерфейс: нажмите кнопку "📊 Оценить метрики"

## Конфигурация

Основные параметры настраиваются в `config/config.py`:

- `RSS_FEEDS` - словарь RSS-лент для парсинга
- `TAXONOMY_SELECTION` - выбранные узлы таксономии (discipline, ga, activity) для фильтрации
- `DEFAULT_HOURS_BACK` - окно времени для сбора статей (по умолчанию 72 часа)
- `DEFAULT_EMBED_THRESHOLD` - порог для фильтрации по эмбеддингам
- `GIGACHAT_CREDENTIALS` - учетные данные для GigaChat API

## API Endpoints

Веб-сервер предоставляет следующие endpoints:

- `GET /` - Главная страница с веб-интерфейсом
- `GET /api/pipeline/run` - Запуск пайплайна (SSE для прогресса)
- `GET /api/pipeline/result` - Получение последнего результата
- `POST /api/metrics/evaluate` - Оценка метрик на датасете
- `GET /docs` - Интерактивная документация API (Swagger)

## Технологии

- **Python 3.10+**
- **FastAPI** - веб-фреймворк
- **pandas** - обработка данных
- **feedparser** - парсинг RSS
- **pymorphy3** - лемматизация русского текста
- **sentence-transformers** - генерация эмбеддингов
- **trafilatura** - извлечение текста из веб-страниц
- **gigachat** - LLM для суммаризации
- **langgraph** - оркестрация LLM workflow
